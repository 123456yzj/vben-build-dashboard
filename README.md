# vben-build-dashboard (Web 运维构建与分支管理控制台)

专为运行于 Ubuntu 服务器的 Monorepo / 多仓前端项目设计的轻量化运维构建与分支管理工具。

## 核心特性

- **多子包总览**：自动识别 Monorepo 根目录与 `apps/*` 独立子仓，卡片式展示分支、最新提交与未提交改动。
- **自动化分支管理**：支持一键 fetch、单包/多包联动切分支、工作区冲突暂存（Stash）拦截、失效与已合并分支一键清理、受保护分支锁定。
- **构建控制台 & 内存防 OOM**：支持单选/多选/全量打包，支持 Turbo 并行构建与队列串行构建切换，实时推流控制台日志，动态注入 `NODE_OPTIONS=--max-old-space-size` 严格限制构建内存上限。
- **产物定向传输与网页下载**：产物默认保存在代码目录，网页端支持一键下载 Zip，并支持将各子包产物自动/手动定向同步至本地服务器目标部署目录（带自动备份快照）。
- **环境维护与多版本管理**：支持 `pnpm install` 与深度重装、清理 `.turbo`/`dist`/`vite` 缓存，原生桥接服务器已有的 `nvm` 快速切换 Node.js 运行时及 pnpm 版本。

## 快速开始

```bash
# 1. 进入工具目录
cd web-build-dashboard

# 2. 安装轻量运行依赖
npm install

# 3. 启动控制台服务
npm start
```

服务启动后默认监听 `http://0.0.0.0:9527`。
- 本地 Ubuntu 可直接访问：`http://localhost:9527`
- 远程电脑直接通过浏览器访问：`http://<server-ip>:9527`
